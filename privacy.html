Política de Privacidade

O stream-metadata-updater é uma ferramenta pessoal que roda inteiramente no computador do próprio desenvolvedor/usuário — não existe servidor remoto, banco de dados externo ou serviço na nuvem envolvido.

O aplicativo se conecta às APIs da Twitch, Kick e YouTube usando OAuth, exclusivamente para ler e atualizar o título, categoria e tags da live do próprio usuário autenticado. Nenhum dado de terceiros é acessado, coletado ou compartilhado.

Os tokens de acesso obtidos via OAuth ficam armazenados apenas localmente, em um arquivo no computador do usuário (tokens.json), e nunca são transmitidos a nenhum outro serviço além das próprias APIs oficiais das plataformas (Twitch, Kick, Google/YouTube).

Como essa é uma ferramenta de uso estritamente pessoal (um único usuário, o próprio desenvolvedor), não há coleta de dados de terceiros, cookies, analytics ou qualquer forma de rastreamento.

Dúvidas: veja o contato no repositório do projeto no GitHub.
